# Big Pay Whish — POS Terminal (TOPWISE T6D)

Interactive design prototype. Opens in any modern browser, no build step.

- `index.html` — merchant terminal (main screen)
- `customer-display.html` — customer-facing second screen

## Publish with GitHub Pages

Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)` → Save.
The site appears at `https://<user>.github.io/<repo>/` and the second screen at `https://<user>.github.io/<repo>/customer-display.html`.
